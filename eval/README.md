# 문장 찾기 평가

프롬프트·모델을 바꿀 때마다 같은 질문으로 돌려 전·후 숫자를 비교한다. 채점은 코드로 한다 (LLM 심판 없음).

```bash
node --env-file=.env.local eval/run.ts              # 질문마다 한 번씩 (진짜 LLM, 25문항 ≈ $0.1: ② 가 후보 50권을 받아 입력 5~7천 토큰)
node --env-file=.env.local eval/run.ts --snapshot   # 정보나루 후보를 새로 받은 뒤 돌린다
```

- `npm test` 에 넣지 않는다. 판 차이가 2문항 이하면 같은 판을 손으로 한 번 더 돌려 본다
- AI Gateway 무료 등급은 몰아 부르면 429 를 준다. 그래서 문항 사이 10초를 띄우고, 429 면 30·60·120초 기다렸다 그 문항만 다시 부른다 (25문항 5분쯤). 그래도 429 가 남으면 비교표 메모에 `무효` 로 적힌다
- 앱과 같은 파이프라인 (`lib/ask/run.ts`) 과 대표 파일 `lib/llm.ts` 를 그대로 쓴다. 하루 상한·기록은 거치지 않는다

## 질문 `questions.json` (대표가 30개)

`{ id, sentence, expect: { keywords?, age?, kdc?, addCode? }, goodIsbns?, badIsbns?, memo? }`

- `expect` 는 적은 칸만 채점한다. 값이 여럿 (배열) 이면 그중 하나면 맞음. `keywords` 는 하나라도 들어 있으면 맞음
- 값: `age` = 정보나루 연령 코드 (`a8` 1·2학년, `a10` 3·4학년, `a12` 5·6학년, `a14` 중등, `a17` 고등, `0` 영유아, `6` 유아, `8` 초등, `14` 청소년, `20`~`60` 어른) / `kdc` = KDC 대분류 `"0"`~`"9"` / `addCode` = 부가기호 첫 자리 (`7` 아동, `4` 청소년, `0` 교양 …). 목록은 `lib/ask/guard.ts`
- 코드로 못 재는 조건 ("짧은" 등) 은 `memo` 에

## 스냅샷 `snapshots/<id>.json` (git 에 안 올림)

문항마다 `expect` 조건으로 정보나루 후보를 한 번 받아 둔다 (책 7칸 + classNo, 표지·책소개 없음). 칸마다 **첫 값** 하나만 쓴다 (낱말도 첫 값 하나, 여럿이면 정보나루가 AND 라서). 그래서 배열은 검색에 쓸 값을 맨 앞에 둔다. ② 는 늘 이 후보로 고른다 → 프롬프트·모델 차이만 보인다. 결과 파일의 스냅샷 해시로 같은 후보였는지 확인한다.

## 지표

|     | 지표             | 계산                                                                                                                        |
| --- | ---------------- | --------------------------------------------------------------------------------------------------------------------------- |
| ①   | 조건 정답률      | expect 칸이 모두 맞은 문항 / 전체 (① 실패는 틀림. 단 경계 expect {} 는 ① 실패도 맞음, 어른 대상 부가기호는 비워도 맞음)     |
| ②   | 조건 맞는 비율   | 고른 책 중 expect 의 KDC 앞자리·부가기호 첫 자리에 맞고 badIsbns 가 아닌 책 / 고른 책. 괄호 = goodIsbns 중 5권 안에 든 비율 |
| ③   | 가드레일로 뺀 수 | 후보 밖 ISBN 합. 0 이 아니면 그 판 불합격                                                                                   |
| ④   | 폴백률           | outcome 이 ai 가 아닌 문항 / 경계 (expect {}) 를 뺀 문항                                                                    |
| ⑤   | 걸린 시간        | ①+② ms 의 중앙값·느린 10%                                                                                                   |
| ⑥   | 요청당 비용      | 평균 $ (PRICE_PER_MTOK 정가)                                                                                                |

결과 파일 `results/<날짜>-<판>-<모델>.json` (같은 날 다시면 `-2`): 판·모델·질문 해시·스냅샷 해시·summary + 문항별 결과. 이유 글·제목은 넣지 않는다. 틀린 것 5개 (문장·기대·나온 조건·고른 책 제목·이유) 는 실행 끝에 터미널에만 나온다. 가짜 llm (`fake`) 판은 아래 표에 넣지 않는다.
